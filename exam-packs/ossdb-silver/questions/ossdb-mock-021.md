# Question

クラスタ内の全データベースに加え、ロールやテーブルスペースなどのグローバルオブジェクトをSQLスクリプトとしてバックアップしたい。最も適切なコマンドを1つ選びなさい。

# Explanation

`pg_dumpall`はクラスタ内の全データベースに加え、ロールやテーブルスペースなどのグローバルオブジェクトをSQLスクリプトとして出力できます。

したがって正解は、**B. `pg_dumpall`**です。

- A：原則として1データベースが対象です。
- C：クラスタの物理ベースバックアップを取得します。
- D：標準コマンドではありません。
- E：制御情報を表示するコマンドです。

**試験テクニック：** コマンド名の`all`と「全DB＋グローバル」を結び付けます。

[問題へ戻る](模擬試験_問題.md#q21)
