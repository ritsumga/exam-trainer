# Question

`VACUUM FULL`に関する正しい記述を2つ選びなさい。

# Explanation

`VACUUM FULL`は表を新しいディスクファイルへ書き換えて圧縮するため、未使用領域をOSへ返せます。一方、強い`ACCESS EXCLUSIVE`ロックと追加領域が必要です。

したがって正解は、**A、B**です。

- A：正しい記述です。
- B：正しい記述です。
- C：書換え先の追加ディスク領域が必要です。
- D：autovacuumは通常のVACUUMを行い、FULLを自動実行しません。
- E：統計更新だけではありません。

**試験テクニック：** FULLには「縮む代わりに、強いロック・重い処理」という代償があります。
