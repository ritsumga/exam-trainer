# Question

副問い合わせに関する正しい記述を2つ選びなさい。

# Explanation

スカラ副問い合わせは単一値として使うため1行1列を返します。`EXISTS`は副問い合わせの結果に行が存在するかだけを判定します。

したがって正解は、**A、B**です。

- A：正しい記述です。複数行を返すとエラーになります。
- B：正しい記述です。
- C：通常の単一式とのINでは1列を返します。
- D：相関副問い合わせは外側の列を参照します。
- E：SELECT句やFROM句などでも利用できます。

**試験テクニック：** scalar＝単一値、EXISTS＝有無、correlated＝外側参照、と英単語で処理します。
