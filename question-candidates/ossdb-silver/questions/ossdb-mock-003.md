# Question

DBMSの役割として、最も不適切なものを1つ選びなさい。

# Explanation

DBMSはデータ操作、同時実行制御、回復、セキュリティなどを担いますが、物理ディスクそのものの修理はハードウェアやOS、運用担当の領域です。

したがって正解は、**E. 故障した物理ディスクをハードウェアとして修理する**です。

- A〜D：いずれもDBMSが提供する主要機能です。
- E：DBMSは冗長化や障害回復を支援できますが、機器を物理的に修理しません。

**試験テクニック：** 「直接、物理的に修理」のようにDBMSの外側の作業を述べる選択肢は消せます。
