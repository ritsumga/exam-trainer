# Question

スキーマと`search_path`に関する正しい記述を2つ選びなさい。

# Explanation

スキーマは1つのデータベース内の名前空間です。`search_path`はスキーマ名を省略したオブジェクト名の探索順序と、通常は作成先スキーマの決定に関係します。

したがって正解は、**A、B**です。

- A：正しい記述です。
- B：正しい記述です。
- C：複数のスキーマを作成できます。
- D：クラスタは作成されません。
- E：`public`スキーマはデータベースごとに存在します。

**試験テクニック：** 階層は「クラスタ＞データベース＞スキーマ＞表」。スキーマをクラスタと混同する選択肢を消します。
