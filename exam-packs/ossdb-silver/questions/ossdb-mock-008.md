# Question

PostgreSQLの開発コミュニティに関する正しい記述を2つ選びなさい。

# Explanation

PostgreSQLはオープンなコミュニティで開発され、コード以外にもバグ報告、文書、翻訳、テストなど多様な参加方法があります。開発中のソースコードも公開されています。

したがって正解は、**B、D**です。

- A：招待だけが参加条件ではありません。
- B：正しい記述です。
- C：単一企業の製品部門ではありません。
- D：正しい記述です。
- E：地域を問わず参加できます。

**試験テクニック：** OSSコミュニティの説明で「単一企業」「招待必須」「地域限定」は不自然な絶対表現です。
