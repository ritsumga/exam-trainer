# Question

`pg_ctl`で実行できる操作として、誤っているものを1つ選びなさい。

# Explanation

`pg_ctl`はサーバプロセスの起動、停止、再起動、再読み込み、状態確認などを管理します。論理バックアップは担当しません。

したがって正解は、**E. データベース単位の論理バックアップ**です。

- A〜D：いずれも`pg_ctl`の用途です。
- E：`pg_dump`の用途です。

**試験テクニック：** `pg_ctl`の`ctl`はサーバのcontrol。データ内容の退避が出たら別コマンドです。
