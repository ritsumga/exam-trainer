# Question

JavaScriptで、一意な値の集まりを保持する組み込みオブジェクトはどれですか。

# Explanation

`Set`は同じ値を重複して保持しないコレクションです。

## a

`Array`は同じ値を複数要素として保持できます。

## b

`Set`は各値を一度だけ保持します。

## c

`Promise`は非同期処理の完了状態を表します。

## d

`Date`は日時を扱います。
