# 工程承認台帳

## 運用

- 判定は`未着手`、`実施中`、`レビュー待ち`、`差し戻し`、`承認済み`のいずれかとする。
- 承認者欄の既定値は`人（プロジェクトオーナー）`とする。
- 承認済みと記録できるのは、人が当該工程を明示的に承認した後だけとする。
- 承認時は対象コミットと注釈付きタグを必ず記録する。
