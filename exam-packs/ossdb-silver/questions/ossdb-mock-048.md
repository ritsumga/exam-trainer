# Question

関数とプロシージャに関する正しい記述を2つ選びなさい。

# Explanation

関数は式やSELECT内から呼び出せます。プロシージャは`CALL`で呼び出します。PL/pgSQLでは変数、条件分岐、繰返し、例外処理などを記述できます。

したがって正解は、**A、B**です。

- A：正しい記述です。
- B：正しい記述です。
- C：ボラティリティや権限などの条件はありますが、関数もSQLを通じてデータを変更できます。
- D：プロシージャを関数のような単一スカラ戻り値で定義するとは限りません。
- E：条件分岐や繰返しを記述できます。

**試験テクニック：** functionはSELECT、procedureはCALL。この呼出し方の違いを最優先で確認します。
