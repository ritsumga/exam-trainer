# Question

シーケンスに関する記述として、最も適切なものを1つ選びなさい。

# Explanation

シーケンスは複数セッションから一意な番号を効率よく払い出します。ただしロールバックした値などにより欠番が生じることがあります。

したがって正解は、**B**です。

- A：`nextval`で消費した値は通常ロールバックされません。
- B：正しい記述です。
- C：表とは独立したデータベースオブジェクトです。
- D：そのセッションで`nextval`を呼ぶ前の`currval`はエラーになります。
- E：欠番なしは保証されません。

**試験テクニック：** シーケンスは「一意は狙える、連続は保証しない」。欠番なしと書かれたら除外します。
