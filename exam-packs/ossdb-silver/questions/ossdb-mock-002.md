# Question

PostgreSQLのバージョンとリリース方針に関する正しい記述を2つ選びなさい。

# Explanation

バージョン9以前は先頭2要素がメジャーバージョンであり、9.6.xなら9.6がメジャーです。各メジャーバージョンは原則として最初のリリースから5年間サポートされます。

したがって正解は、**A、D**です。

- A：正しい記述です。
- B：10以降は先頭の14がメジャー、後ろの3がマイナーです。
- C：メジャーバージョン間ではデータディレクトリの物理互換性は保証されません。
- D：正しい記述です。
- E：マイナーリリースは主に不具合やセキュリティ修正で、新機能追加は原則メジャーリリースです。

**試験テクニック：** 「9以前は2桁、10以降は先頭だけ」を先に思い出すと、バージョン表記の選択肢を速く処理できます。
