# Question

インデックスに関する正しい記述を2つ選びなさい。

# Explanation

インデックスは条件や並べ替えに応じて検索を高速化できますが、格納領域を使い、INSERT、UPDATE、DELETE時に保守コストが発生します。

したがって正解は、**A、C**です。

- A：正しい記述です。
- B：更新対象のインデックス保守により遅くなる場合があります。
- C：正しい記述です。
- D：B-treeは等価比較や範囲比較に広く使えます。
- E：主キーやUNIQUE制約などに伴うものを除き、全列には自動作成されません。

**試験テクニック：** インデックスの選択肢で「必ず高速」「全列自動」は強すぎるので消せます。
