# Question

次の受注明細表では、主キーが（受注番号, 商品番号）であり、商品番号から商品名と単価が一意に決まる。

`受注明細(受注番号, 商品番号, 商品名, 単価, 数量)`

第2正規形にするための対応として、最も適切なものを1つ選びなさい。

# Explanation

複合主キーの一部である商品番号だけから商品名と単価が決まるため、部分関数従属があります。これを除くには商品情報を商品表へ分離します。

したがって正解は、**B. 商品番号、商品名、単価を商品表として分離する**です。

- A：数量は受注番号と商品番号の組合せに従属する明細情報です。
- C：受注番号だけでは商品名や単価は決まりません。
- D：第1正規形にも反する方向です。
- E：重複行の削除は正規化ではありません。

**試験テクニック：** 複合主キーの問題で「キーの一部分→非キー列」が見えたら、第2正規形違反です。
