# Question

`pg_hba.conf`に上から次の順で設定されている。ホスト`192.168.1.50`から、ユーザ`app`がデータベース`sales`へTCP/IP接続する場合に適用される認証方式を1つ選びなさい。

```text
host  sales  app  192.168.1.0/24  scram-sha-256
host  all    all  0.0.0.0/0       reject
host  sales  app  192.168.1.50/32 trust
```

# Explanation

`pg_hba.conf`は上から順に評価され、接続条件に最初に一致した1行だけが使用されます。1行目が対象接続に一致するため、後ろのより具体的なtrust行までは進みません。

したがって正解は、**C. scram-sha-256**です。

- A：3行目まで評価されません。
- B：2行目より先に1行目が一致します。
- C：1行目の認証方式です。
- D、E：一致した行に指定されていません。

**試験テクニック：** HBA問題は「最も具体的な行」ではなく、必ず「上から最初に一致」です。
