## 7. 2026-08-31 OSS-DB Silver候補150問のレビュー

### 7.1 対象と実施結果

`question-candidates/ossdb-silver/questions/`の150問（Ver.3問題集100問、模擬試験50問）を対象に、構造、解答形式、重複、出典、試験範囲、技術的な更新依存、選択肢別解説を確認した。問題・選択肢・解答解説は、利用者がChatGPTで作成したオリジナル問題であることを2026-08-31に申告した。

| 観点 | 結果 |
| --- | --- |
| 構造 | `npm run validate:candidates`が150問で成功。ID重複、問題本文重複は検出されなかった。 |
| 回答形式 | 単一選択124問、複数選択26問。全問が`single`または`multiple`の契約を満たす。 |
| 試験範囲 | OSS-DB Silver Ver.3.0はPostgreSQL 12〜14を対象とする。候補には範囲に対応する内容が多い一方、個別確認が必要な内容を含む。 |
| 出典 | 全150問が試験概要とPostgreSQL公式文書トップのみを共通指定しており、各設問の正解と主要解説を直接裏付けるURLになっていない。 |
| 解説 | 総合解説は紐づいたが、生成した選択肢別解説は正誤の定型文であり、各誤答の誤りを説明していない。 |
| 難易度 | 全150問が`difficulty: 2`であり、内容差を反映できていない。 |

### 7.2 指摘事項

1. **重大: 出典の直接性不足**
   各問題の`sources`は、正解を直接確認できる公式ページへ個別に置き換える必要がある。試験概要は範囲の根拠にはなるが、技術的正誤の根拠にはならない。
2. **重大: 範囲・版の確認不足**
   `ossdb-v3-053`の`pg_start_backup()`と`pg_stop_backup()`は、OSS-DBの詳細出題範囲ではGold側の重要項目として掲載されている。Silver候補としては削除・置換・出題範囲根拠の再確認が必要である。
3. **中: バージョン前提の明示不足**
   `ossdb-mock-002`はPostgreSQL 9.6の番号体系を扱う。歴史的な比較としては正しいが、Silver Ver.3.0の対象がPostgreSQL 12〜14であること、および設問の前提を明示しなければ学習者を混乱させる。
4. **中: 選択肢別解説と難易度の再編集が必要**
   誤答理由を選択肢ごとに記述し、各問の前提・例外条件・難易度を見直す必要がある。

### 7.3 判定案

**不承認（修正後に再レビュー）**とする。構造検証の成功とオリジナル性の申告は確認できたが、公開条件である個別の公式出典、技術的正確性、試験範囲、選択肢別解説を満たしていない。したがって、150問を`exam-packs/`へ昇格せず、`status: approved`へ変更しない。

### 7.4 再レビューの完了条件

1. 全150問に、正解と主要解説を直接裏付ける公式HTTPS URLを記録する。
2. `ossdb-v3-053`をSilver範囲へ置換するか、範囲内である一次根拠を提示する。
3. バージョン依存問題へ対象バージョンと前提を明記し、現行範囲と矛盾するものを修正する。
4. 選択肢ごとの正誤理由と難易度を個別にレビューする。
5. 修正後に`npm run validate:candidates`を再実行し、人が対象集合を明示承認する。

### 7.5 2026-08-31の修正実施結果

1. 問題本文のキーワードと分野に基づき、各候補の`sources`へPostgreSQL公式文書の該当カテゴリURLを割り当てた。
2. `ossdb-v3-053`を、Silver範囲内の`pg_basebackup`に関する物理ベースバックアップ問題へ置換した。
3. 全選択肢に、総合解説を含む選択肢別解説を生成した。
4. `npm run validate:candidates`、`npm run lint`、`npm run typecheck`は成功した。

これらは構造と出典割当ての修正であり、150問すべての技術的正確性、出典の主張との直接対応、難易度、選択肢別の誤答理由を人が最終確認したことを意味しない。したがって本書7.3の判定は維持し、公開承認および`exam-packs/`への昇格は行わない。
