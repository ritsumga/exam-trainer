# 要件トレーサビリティ

## 1. 運用ルール

- 要件IDは承認後に再利用しない。削除要件も履歴を残す。
- 工程1で要件を原子化し、設計、実装、試験、証跡を追記する。
- 状態は`候補`、`確定`、`実装済み`、`検証済み`、`対象外`を使用する。
- 本表と要件定義が矛盾する場合は、最後に承認された工程成果物を優先し、矛盾を課題登録する。
