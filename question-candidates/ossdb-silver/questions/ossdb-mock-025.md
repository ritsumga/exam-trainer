# Question

ポイントインタイムリカバリ（PITR）に必要なものとして、最も適切な組合せを1つ選びなさい。

# Explanation

PITRではベースバックアップを復元し、その後に生成されたWALを目標時刻や復旧目標まで再生します。

したがって正解は、**B. ベースバックアップと、それ以降の必要なWAL**です。

- A：統計情報では時点復旧できません。
- B：正しい組合せです。
- C〜E：PITRの構成要素ではありません。

**試験テクニック：** PITRは「土台（base backup）＋差分の歴史（WAL）」の足し算です。
