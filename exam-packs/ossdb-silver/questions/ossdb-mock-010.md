# Question

テンプレートデータベースに関する正しい記述を2つ選びなさい。

# Explanation

新規データベースは既定で`template1`を複製します。`template0`は初期状態に近い変更されないテンプレートで、異なるエンコーディングやロケールを指定する場合などにも使われます。

したがって正解は、**A、C**です。

- A：正しい記述です。
- B：`template0`は通常変更しません。
- C：正しい記述です。
- D：テンプレートも同じクラスタ内のデータベースです。
- E：任意のデータベースをテンプレートとして利用でき、固定名ではありません。

**試験テクニック：** `template1`は「普段のコピー元」、`template0`は「手を加えない原本」と覚えます。
