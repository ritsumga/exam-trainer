# Question

WALに関する正しい記述を2つ選びなさい。

# Explanation

WALはWrite-Ahead Loggingの略で、データファイルへの変更より先にログへ記録することで障害回復を可能にします。継続的に保存したWALはPITRにも使えます。

したがって正解は、**A、C**です。

- A：正しい記述です。
- B：実行計画の保存機構ではありません。
- C：正しい記述です。
- D：PostgreSQLの基本的な回復機構として動作します。
- E：物理的変更を表すログであり、SQLスクリプトそのものではありません。

**試験テクニック：** WALは名前どおり「Write Ahead＝先に書く」。これだけでAを確定できます。
