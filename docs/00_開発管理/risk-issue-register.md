# リスク・課題台帳

## 1. 運用ルール

- 種別は`リスク`または`課題`、状態は`未対応`、`対応中`、`監視中`、`解消`、`受容`とする。
- 発生可能性と影響度は`低`、`中`、`高`で記録する。
- 工程の完了を妨げる項目は承認依頼時に明示する。
- 解消しても行を削除せず、対応と根拠を残す。
