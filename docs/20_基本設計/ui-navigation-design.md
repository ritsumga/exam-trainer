# Exam Trainer 画面・遷移基本設計

## 1. 目的

本書は、v1の画面構成、URL、主要状態遷移、レスポンシブ表示、キーボード操作の共通規則を定める。最終文言、配色値、コンポーネントAPIは工程3で確定する。

## 2. アプリケーションシェル

全画面はヘッダー、主コンテンツ、通知領域から構成する。ヘッダーには製品名、現在の試験名、試験選択へ戻る操作を表示する。通知領域はオフライン準備完了、更新可能、保存失敗などを`aria-live`で通知する。

通常画面ではブラウザの戻る操作を許可する。未送信入力、未完了模試、復元実行中などデータ消失の可能性がある場合は、対象操作の直前に確認する。

## 3. URL一覧

| URL | 画面 | 主な責務 |
| --- | --- | --- |
| `/#/exams` | 試験選択 | Pack一覧、学習済み数、正答率、最終学習日時を表示する |
| `/#/exams/:examId` | 試験ホーム | 演習、模試、成績、データ管理への入口を表示する |
| `/#/exams/:examId/practice/setup` | 演習設定 | モード、分野、問題数を指定し、候補数を確認する |
| `/#/exams/:examId/practice/:sessionId` | 通常演習 | 回答、採点、解説、理解度、お気に入り、前後移動を扱う |
| `/#/exams/:examId/mock/setup` | 模擬試験設定 | 問題数、制限時間、割当結果、問題不足を表示する |
| `/#/exams/:examId/mock/:sessionId` | 模擬試験 | 回答、問題移動、見直し、残り時間、提出を扱う |
| `/#/exams/:examId/mock/:sessionId/result` | 試験結果 | 得点、分野別結果、誤答、未回答、見直し対象を表示する |
| `/#/exams/:examId/statistics` | 成績 | 全体・分野別成績、弱点、模試履歴、回答時間傾向を表示する |
| `/#/settings/data` | データ管理 | バックアップ出力、復元検証、プレビュー、全置換を扱う |

`/`は`/#/exams`相当へ誘導する。不明な`examId`または`sessionId`は見つからない状態を表示し、安全な戻り先を提示する。

## 4. 主要画面

### 4.1 試験選択

- 軽量カタログを読み込み、Packごとの学習要約とともにカード表示する。
- Packが0件なら、利用者向けの空状態と開発者向けPack配置文書への案内を表示する。
- 読込失敗したPackを黙って除外せず、アプリ全体のデータ不整合としてエラーを表示する。

### 4.2 試験ホーム

- 弱点、未回答、誤答、お気に入り、ランダム、分野別、模擬試験、成績の入口を表示する。
- 対象件数が0件の演習モードは開始不可とし、理由と次に可能な操作を示す。
- 当該試験に未完了模試がある場合、再開または破棄を選ぶダイアログを優先表示する。

### 4.3 通常演習

- 回答確定前は設問、選択肢または入力欄、進捗、お気に入り、前後移動を表示する。
- 回答確定後は正誤、正解、自分の回答、詳細解説、選択肢別解説、理解度、出典を同じ画面に追加する。
- `multiple`では必要選択数を表示する。未回答の確定操作は許可しない。
- 保存失敗時は回答済み表示へ進まず、再試行または安全な離脱を案内する。

### 4.4 模擬試験設定・実施

- 問題数と制限時間はPack既定値を初期値とし、1以上かつPack上限以下だけを許可する。
- 全体問題不足時は必要数、利用可能数、不足数を示して開始不可とする。
- 分野不足を再配分した場合は、設定比率との差と実際の分野別問題数を開始前に確認させる。
- 実施画面では解説と正誤を隠し、残り時間、現在位置、回答済み数、未回答数、見直し数を常時表示する。
- 手動提出は未回答数を含む確認ダイアログを経る。期限到達時は確認なしで自動提出する。

### 4.5 試験結果・成績

- 結果画面は得点、全体正答率、分野別の問題数・正答数・正答率、回答時間、誤答、未回答、見直し対象を表示する。
- 誤答のみ再演習は、回答のある誤答問題だけを対象に通常演習設定へ渡す。未回答は未回答モードから扱う。
- 成績画面は全体、分野別、弱点、模試履歴、回答時間傾向を分離し、該当データがない場合は空状態を表示する。

### 4.6 データ管理

- バックアップ出力前に対象件数と保存上の注意を表示する。
- 復元ファイル選択後は、構文・版・スキーマ・参照整合性の全検証が成功した場合だけプレビューへ進む。
- プレビューでは現行件数と置換後件数を対象別に表示し、明示確認後だけ全置換する。
- 失敗時は既存データが変更されていないことと理由を表示する。

## 5. ダイアログと通知

| 状態 | 表示方式 | 確定操作 |
| --- | --- | --- |
| 未完了模試 | モーダル | 再開、破棄、閉じる |
| 模試破棄 | 確認モーダル | 破棄、戻る |
| 分野再配分 | 設定画面内警告 | 内容を確認して開始 |
| 全体問題不足 | 設定画面内エラー | 設定変更または戻る |
| 手動提出 | 確認モーダル | 提出、戻る |
| 時間切れ | モーダル兼状態通知 | 自動提出結果へ進む |
| 復元全置換 | 確認モーダル | 置換、戻る |
| PWA更新 | 非遮断通知 | 更新、後で |
| 保存・読込失敗 | 状況に応じた通知またはエラー画面 | 再試行、安全な戻り先 |

モーダルはフォーカスを内部に保持し、閉じた後は起点へ戻す。破壊的操作を既定ボタンにしない。

## 6. レスポンシブ設計

- 360px以上1,023px以下は単一カラムを基本とし、主要操作を画面下部または設問直後へ配置する。
- 1,024px以上では設問とナビゲーション、または主結果と補助情報を2領域で表示できる。
- コンテンツ領域は最大1,440pxとし、それ以上の画面でも行長と操作距離を拡大しない。
- 表は狭い画面でカードまたは縦積みに切り替え、ページ全体の横スクロールを発生させない。
- 模擬試験の残り時間と回答状況は、幅にかかわらず固定ヘッダーまたは追従領域から確認可能にする。

## 7. キーボードと読み上げ

- すべての操作要素を`Tab`と`Shift+Tab`で移動し、`Enter`または`Space`で実行できるようにする。
- 選択肢はネイティブのradio、checkbox、labelを優先し、入力式はlabelと説明を関連付ける。
- フォーカスリングを背景との十分な差がある形で常時表示し、色だけで正誤や警告を区別しない。
- 画面遷移後は主見出しへフォーカスを移す。採点結果、期限到達、保存失敗、更新可能は適切な`aria-live`領域で通知する。
- タイマーは毎秒読み上げず、残り時間が一定の節目に達した時だけ通知する。

## 8. 状態遷移の確認観点

- 正常系: 試験選択から通常演習、模試、結果、成績、バックアップへ到達できる。
- 空状態: Packなし、履歴なし、対象問題なし、模試履歴なしから安全に戻れる。
- 異常系: 不明URL、Pack読込失敗、保存失敗、復元失敗を通常画面と区別して表示する。
- 継続系: 再起動後の模試再開、期限超過時の即時自動提出、更新保留後の学習継続が成立する。
