# Question

停止中のPostgreSQL 14クラスタをファイルシステムレベルでコピーした。このコピーを別ホストでそのまま使用する条件として、最も適切なものを1つ選びなさい。

# Explanation

ファイルシステムレベルの物理コピーはデータ格納形式に依存します。同じメジャーバージョンで、CPUアーキテクチャやOSなどが互換である必要があります。

したがって正解は、**A**です。

- A：最も適切です。同一メジャー内のマイナー更新では物理形式の互換性が維持されます。
- B：同じ14系なら14.0だけに限定されません。
- C：メジャーバージョン15へデータディレクトリをそのまま持ち込めません。
- D、E：バージョンやDBMSを問わず使えるのは論理バックアップの特徴に近い説明です。

**試験テクニック：** 物理バックアップを見たら「同一メジャー」、論理バックアップを見たら「移行に強い」と整理します。
