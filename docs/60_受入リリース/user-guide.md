# Exam Trainer 利用ガイド

## 1. 対象

本書はExam Trainer v1の利用方法と、ローカル保存データを安全に扱うための注意を説明する。Exam Trainerは各試験運営団体の公式製品ではない、学習目的の独立したプロジェクトである。

## 2. 学習を始める

1. 試験選択画面で利用するExam Packを選ぶ。
2. 試験ホームから通常演習、模擬試験、成績、データ管理のいずれかへ進む。
3. 通常演習では、未回答、誤答、弱点、お気に入り、分野別、ランダムを選び、問題数を指定する。
4. 回答を確定すると、正誤、正解、自分の回答、解説、選択肢別の理由、出典を確認できる。
5. 回答後に理解度を記録し、必要な問題をお気に入りへ追加する。

`multiple`は表示された個数をすべて選択したときだけ完全一致で採点する。`input`は大文字小文字、全角半角、内部空白を区別するため、問題文の入力指定に従う。

## 3. 模擬試験

- 問題数と制限時間は、画面に表示される範囲内の正整数を指定する。
- 試験中は解説を表示しない。回答、問題移動、見直し変更のたびに未完了状態を保存する。
- ブラウザを閉じても絶対期限まで時間は進む。再び開くと、未完了試験を再開または破棄できる。
- 期限へ達すると自動提出する。未回答も得点の分母に含まれる。

OSS-DB Silver学習用Packのv1同梱問題は10問であり、公式試験の約50問を再現するものではない。短縮模試として利用する。

## 4. インストールとオフライン利用

対応ブラウザで公開版を一度オンライン表示すると、ブラウザのインストール操作からPWAとして追加できる。オフラインで再び開いた場合も、事前取得済みの問題演習、採点、解説、履歴保存、模試再開、成績確認を利用できる。

更新通知が表示された場合は、保存操作が完了していることを確認してから「更新する」を選ぶ。「後で」を選ぶと現在の版を継続し、次回以降に再通知する。

## 5. 学習データとバックアップ

学習データは、利用中のブラウザと公開元URLに対応するIndexedDBだけへ保存する。サーバー送信、ログイン同期、端末間同期は行わない。次の場合に履歴を失う可能性がある。

- ブラウザのサイトデータ、Cookie、キャッシュ等を削除した場合
- プライベートブラウズを終了した場合
- ブラウザ、ブラウザプロファイル、端末、公開元URLを変更した場合
- 端末またはブラウザの保存領域が故障・初期化された場合

重要な学習の後やブラウザ設定を変更する前に、データ管理画面の「JSONをダウンロード」でバックアップを作り、別の保存場所へ保管する。バックアップには回答履歴、お気に入り、復習状態、模擬試験、設定を含むが、問題本文は含まない。

復元では、ファイルを選ぶと現在件数と復元後件数を表示する。確認チェックを入れて実行すると、現在の対象データをすべて置き換える。マージは行わないため、必要なら復元前にも現在のバックアップを作る。不正データ、未対応版、保存失敗の場合は既存データを変更しない。

## 6. 既知制約

- v1はログイン、クラウド同期、ランキング、課金、AI問題生成を提供しない。
- 利用者が画面からExam Packを追加・更新・削除する機能はない。
- 学習データの保持はブラウザの保存方針と空き容量に依存する。
- 同梱問題は学習用の独自問題であり、合格や公式試験内容との一致を保証しない。
