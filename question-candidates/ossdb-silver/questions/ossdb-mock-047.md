# Question

宣言的パーティショニングに関する記述として、最も適切なものを1つ選びなさい。

# Explanation

宣言的パーティショニングでは親をPARTITIONED TABLEとして定義し、RANGE、LIST、HASHなどの方式とパーティションキーに従って行を子パーティションへ格納します。

したがって正解は、**A**です。

- A：正しい記述です。
- B：同じデータベース内の表として作成でき、別クラスタは必須ではありません。
- C：RANGE、LIST、HASHを利用できます。
- D：格納先はパーティションキーで決まります。
- E：制約も定義できます。

**試験テクニック：** partition keyという名前自体が「振り分け基準」を示します。
