# Question

システムカタログと情報スキーマに関する正しい記述を2つ選びなさい。

# Explanation

システムカタログはPostgreSQL固有の内部情報を保持し、主に`pg_catalog`にあります。情報スキーマはSQL標準に基づき、移植性を意識したビューを提供します。

したがって正解は、**A、C**です。

- A：正しい記述です。
- B：PostgreSQL固有なのは主にシステムカタログです。
- C：正しい記述です。
- D：権限の範囲でユーザも参照できます。
- E：表や列などオブジェクト定義情報を含みます。

**試験テクニック：** `information_schema=標準・移植性`、`pg_catalog=固有・詳細`の対比で即答します。
