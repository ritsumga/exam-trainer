# Question

`COPY`とpsqlの`\copy`に関する正しい記述を2つ選びなさい。

# Explanation

SQLの`COPY`はサーバプロセス側のファイルを扱い、psqlの`\copy`はクライアント側のファイルを扱います。

したがって正解は、**A、B**です。

- A：正しい記述です。
- B：正しい記述です。
- C：いずれも表データの入出力で、クラスタの物理コピーではありません。
- D：`\copy`はpsqlのメタコマンドです。
- E：`COPY`の中心的な用途が表データの入出力です。

**試験テクニック：** バックスラッシュ付きはpsql側、つまりクライアント側と覚えます。
